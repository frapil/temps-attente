Mes cartes

Pour transférer vos cartes vers un autre appareil : exportez ou copiez ici, puis importez là-bas (fichier ou texte collé).
Données : PRIM – Île-de-France Mobilités
Clé API PRIM absente : créez un compte sur prim.iledefrance-mobilites.fr, générez un jeton, puis ajoutez PRIM_API_KEY=votre_jeton dans le fichier .env et relancez le serveur.
Saisissez votre jeton PRIM pour afficher les horaires. Créez-le sur prim.iledefrance-mobilites.fr (« Mon jeton d'authentification »). Il reste uniquement sur cet appareil.
Quota PRIM atteint : les horaires affichés ne sont plus actualisés (prochain essai automatique vers , ou ⟳). Le jeton par défaut est limité à 1 000 requêtes par jour et 5 par seconde. Pour l'éviter, demandez des quotas augmentés, c'est gratuit : connectez-vous sur la page de l'API Prochains passages puis « Gérer mes quotas ».
